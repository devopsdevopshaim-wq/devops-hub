# פאנל — סטודיו קומיקס מצילומים

אתר בעברית שהופך צילומים לעמודי קומיקס. מעלים עד 100 תמונות, בוחרים את אלה שנכנסות לסיפור, מלבישים עליהן סגנון ציור ומרכיבים עמוד עם פאנלים ובועות דיבור. אחר כך מורידים PNG, JPG או PDF.

כתובת: https://devopsdevopshaim-wq.github.io/devops-hub/comic-studio/

## יצירת קומיקס אמיתי (ציור בשרת)

זה הלב של האתר. מסך **יצירת קומיקס** שולח את התמונות לשרת הציור של האתר ב-n8n (`n8n/hasadna-comic.json`), והוא מצייר אותן במודל תמונות אמיתי: Gemini 2.5 Flash Image או OpenAI gpt-image-1. במצב "אוטומטי" Gemini מצייר, ואם הוא נכשל עוברים ל-OpenAI.

| מה יוצרים | מה מקבלים |
| --- | --- |
| עמוד קומיקס שלם | 3–8 פאנלים, כותרת, בועות דיבור בעברית (או בועות ריקות למילוי בעורך), לפי הסיפור שכותבים |
| דמות קומיקס | כל תמונה נבחרת מצוירת מחדש כאיור, עד 10 בבת אחת |
| סצנה משולבת | 2–4 אנשים מתמונות שונות, יחד בציור אחד |

12 סגנונות: גיבורי-על, גרפיק נובל, מנגה, אנימה, קו נקי אירופאי, קומיקס רטרו, קריקטורה, וובטון, אנימציה תלת-ממדית, ספר ילדים, גרפיטי ונואר. כל תוצאה נשמרת בספרייה, ואפשר לשלוח אותה לעורך העמוד כדי להוסיף בועות ולייצא.

### חיבור המפתחות (פעם אחת)

1. מפתח Gemini: ב-[Google AI Studio](https://aistudio.google.com/apikey) יוצרים מפתח ומפעילים חיוב (ציור עולה סנטים בודדים).
2. מפתח OpenAI: ב-[platform.openai.com/api-keys](https://platform.openai.com/api-keys).
3. ב-GitHub: **devops-hub** ← **Settings** ← **Secrets and variables** ← **Actions** ← **New repository secret**. מוסיפים `GEMINI_API_KEY` ו-`OPENAI_API_KEY` (או אחד מהם).
4. **Actions** ← **Deploy agents to n8n Cloud** ← **Run workflow**. בסיכום הריצה מופיע "סטודיו קומיקס: Gemini ✅ · OpenAI ✅".

המפתחות עוברים מ-GitHub ישירות ל-n8n ולא נכנסים לקוד. השרת מקבל בקשות רק מהאתר עצמו, מגביל כל כתובת ל-24 ציורים בשעה, ויש תקרה של 200 ציורים ביום לכל האתר. הצילומים לא נשמרים ב-n8n.

## סגנונות AI בדפדפן (רשתות נוירוניות)

עשרה סגנונות שמציירים את התמונה מחדש ברשתות שאומנו על ציורים אמיתיים. הם רצים במחשב או בטלפון של המשתמש (WebGL, ואם אין, WebAssembly), והתמונה לא יוצאת מהמכשיר.

| סגנון | מודל | הערות |
| --- | --- | --- |
| קומיקס AI (ברירת המחדל) | CartoonGAN Hosoda + קווי דיו ונקודות הדפסה | |
| פורטרט מצויר | AnimeGANv2 face_paint_512_v2 | הכי טוב לפנים קרובות |
| קריקטורה AI | הגדלת ראש ואז face_paint, עם צביעה בשכבות | לוחצים על הפנים כדי למרכז |
| קריקטורה מצוירת | CartoonGAN Hosoda | |
| אנימה רכה | AnimeGANv2 Hayao | |
| אנימה קולנועית | AnimeGANv2 Shinkai | |
| אנימה עזה | CartoonGAN Paprika | |
| מנגה AI | AnimeGANv2 Shinkai + רשתות גוון בשחור-לבן | |
| נוף מצויר | CartoonGAN Hayao | טוב לרקעים |
| שמיים קולנועיים | CartoonGAN Shinkai | |

המודלים נטענים בפעם הראשונה מ-unpkg (עם גיבוי ב-jsDelivr) מתוך חבילות npm: `sts-animegan@1.0.0` (שלושת מודלי AnimeGANv2 ב-ONNX, כ-8.6MB כל אחד) ו-`local-tfjs-models@0.0.3` (ארבעת מודלי CartoonGAN ב-TensorFlow.js, כ-11MB כל אחד). מנועי ההרצה: `onnxruntime-web@1.20.1` ו-`@tensorflow/tfjs@4.22.0`. אחרי ההורדה הראשונה הכול נשמר במטמון הדפדפן.

רישוי: משקולות Hayao ו-Shinkai של AnimeGAN מותרות לשימוש אישי ואקדמי בלבד. face_paint_512_v2 ברישיון MIT. לשימוש מסחרי צריך לבדוק את רישיונות המודלים.

16 אפקטים מתקדמים (`js/fx-art.js`) שרצים בדפדפן בתוך שנייה-שתיים:

| משפחה | אפקטים |
| --- | --- |
| ציור | ציור שמן (משיכות מכחול לאורך הצורות ותבליט של צבע עבה), סכין ציור, גואש, גיר פסטל, פואנטיליזם, פחם, דיו יפני עם חותמת, ויטראז׳, פסיפס |
| גרפיטי | גרפיטי על קיר לבנים (קו מתאר כפול וטפטופים), סטנסיל רחוב על בטון, גרפיטי ניאון |
| מנגה ואנימה | מנגה אקשן עם קווי פעולה (לוחצים כדי לקבוע את המרכז), שוג׳ו עם זוהר ונצנוצים |
| קומיקס | הדפס CMYK בארבע רשתות, עט כדורי על דף מחברת |

## הנפשה ווידאו

- **הנפשת ציור** (במעבדה): עשרה אפקטים שהופכים את הציור לקטע בלולאה: הציור נבנה (מהצילום לקווים ואז לצבע), לפני ואחרי, קווים חיים, זום אקשן, תנועת מצלמה, גליץ׳, נצנוצים, גשם וברקים, גל נקודות והבהוב ניאון.
- **סרטון מהעמוד** (בעמוד הקומיקס): המצלמה עוברת מפאנל לפאנל לפי סדר הקריאה ובסוף מראה את כל העמוד. סטורי 9:16, פוסט 4:5 או רחב 16:9.
- ההקלטה נעשית בדפדפן (MediaRecorder): MP4 כשהדפדפן תומך (Chrome, Edge ו-Safari עדכניים), אחרת WebM.

## מצב Gemini (אופציונלי)

לציור מחדש ברמת איור אמיתי, יש 12 סגנונות AI: קומיקס גיבורי-על, קריקטורה מוגזמת, אנימציה תלת-ממדית, אנימה, מנגה, גרפיק נובל, צ׳יבי, פלסטלינה, סטיקר, קומיקס רטרו, ציור שמן ומשחק רטרו. יש גם ״שילוב הנבחרות״: מסמנים 2–3 תמונות של אנשים, מתארים סצנה, והמודל מצייר אותם יחד.

- צריך מפתח API של Google Gemini מ-[Google AI Studio](https://aistudio.google.com/apikey). מדביקים אותו בכפתור ״מצב AI״.
- המפתח נשמר רק ב-localStorage של הדפדפן. הבקשה יוצאת ישירות מהדפדפן ל-Google, רק כשלוחצים.
- המודל ברירת מחדל: `gemini-2.5-flash-image`. אפשר לשנות בחלון ההגדרות.
- התוצאה נשמרת בספרייה כתמונה חדשה, ואפשר להלביש עליה גם סגנון מקומי.

## שמירה

התמונות (מוקטנות ל-2000 פיקסלים בצד הארוך) והפרויקט נשמרים ב-IndexedDB של הדפדפן, בלי שרת. ניקוי נתוני הדפדפן מוחק אותם.

## הפעלה מקומית

אין בנייה ואין תלויות. כל שרת סטטי מספיק:

```bash
cd comic-studio
python3 -m http.server 8080
```

ופותחים את `http://localhost:8080`. ייצוא PDF ו-ZIP טוען את jsPDF ו-JSZip מ-cdnjs בפעם הראשונה שמשתמשים בהם.
