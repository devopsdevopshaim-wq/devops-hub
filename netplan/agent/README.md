# NetPlan Agent – הסוכן המקומי של נט־פלאן

תוכנה מקומית למחשב הנייד: מחברים כבל רשת, והיא מזהה את החיבור לבד, מוצאת את כל המכשירים ברשת, בודקת אבטחה וזליגה, ומנטרת תקלות עם פתרונות מוכנים.

הסוכן הוא החלק של נט־פלאן שרץ במחשב עצמו. האתר מתכנן את הרשת; הסוכן סורק את מה שיש עליה בפועל. התוצאות מופיעות בלשונית **"סריקה חיה"** באתר (https://devopsdevopshaim-wq.github.io/devops-hub/netplan/#livescan), שם הן מושוות לתכנית, וגם בלוח מלא משלו בכתובת `http://127.0.0.1:8765`.

**חיבור לאתר:** כשהסוכן פועל, פותחים באתר את "סריקה חיה" (ב-Chrome או Edge) ומאשרים גישה ל"מכשירים ברשת המקומית" כשהדפדפן שואל. הסוכן מקבל בקשות רק מהאתר של נט־פלאן ומהמחשב עצמו. בלשונית "ניטור תעבורה" אפשר לבחור את הסוכן כמקור נתונים חי: `http://127.0.0.1:8765/api/traffic.json`.

## מה היא עושה

| תחום | מה בדיוק |
|---|---|
| **זיהוי חיבור אוטומטי** | מזהה חיבור/ניתוק של כבל (וגם Wi-Fi ו-VPN), ממתינה לכתובת מה-DHCP ומריצה סריקה מלאה. מתריעה אם הכבל מחובר ואין כתובת תוך דקה. |
| **פרטי החיבור** | IP, מסכה, רשת, ראוטר, DNS, MAC, מהירות ודופלקס של הכבל, DHCP או סטטי, שרת DHCP, תוקף החכירה, IP ציבורי וספק האינטרנט. |
| **מלאי מכשירים** | כל מכשיר ברשת: IP, MAC, יצרן (מאגר IEEE מלא), שם (DNS / NetBIOS / mDNS), סוג (ראוטר, שרת, NAS, מחשב, טלפון, מדפסת, מצלמה, טלוויזיה, IoT…) עם הסבר לזיהוי, פורטים פתוחים, ממשקי Web. שומרת היסטוריה לכל רשת: מתי נראה לראשונה ולאחרונה, שינויי כתובת, כינוי, הערות ואישור. |
| **נט פלאן – מפת רשת** | טופולוגיה: אינטרנט ← ספק ← ראוטרים בדרך ← הראוטר שלך ← המכשירים לפי קבוצות. תוכנית כתובות (IP Plan) עם תפוסה וכתובות פנויות. |
| **מסלול ונתבים** | Traceroute עם תפקיד כל נתב: הראוטר שלך, ראוטר נוסף (NAT כפול), CGNAT של הספק, כניסה לספק, וקפיצות השהיה. |
| **אבטחה וזליגה** | הצפנת הקו, אחוז התעבורה המוצפנת ומי שולח בלי הצפנה, יירוט HTTPS, חטיפת DNS, זליגת DNS ו-IPv6 כשיש VPN, ARP Spoofing ושינוי MAC של הראוטר, התנגשות IP, UPnP ושירותי ניהול לא מוצפנים בראוטר, שירותים מסוכנים ברשת (Telnet, RDP, VNC, מסדי נתונים), מכשירים לא מאושרים, חומת אש, Proxy, שרת DHCP זר. ציון מ-0 עד 100. |
| **תקלות ופתרונות** | ניטור רציף של השהיה, איבוד חבילות ו-Jitter לראוטר, לאינטרנט ול-DNS. מזהה: כבל מנותק, כשל DHCP (169.254), אין Gateway, ראוטר לא עונה, אין אינטרנט, DNS תקוע או איטי, לינק 10/100 או Half Duplex (כבל פגום), שגיאות בכרטיס הרשת, MTU, Captive Portal. לכל תקלה: הסבר, שלבי פתרון ופקודות להעתקה. כפתורים לניקוי DNS ולחידוש כתובת. בדיקת מהירות. |
| **התראות ודוחות** | התראות שולחן עבודה על מכשיר חדש, ניתוק ותקלה, יומן אירועים, ייצוא ל-Excel (CSV) ול-JSON, ודוח להדפסה או ל-PDF. |

## התקנה והפעלה

### Windows
1. התקן Python 3.10 ומעלה מ-https://www.python.org/downloads/ (סמן **Add python.exe to PATH**).
2. הורד את התיקייה `netplan` ולחץ פעמיים על **`start.bat`**. הממשק נפתח בדפדפן בכתובת `http://127.0.0.1:8765`.
3. כדי שהתוכנה תעלה לבד עם המחשב ותזהה כל חיבור כבל: `start.bat --install-autostart` (ביטול: `python netplan.py --remove-autostart`).

**קובץ EXE בלי Python:** הרץ פעם אחת `build_exe.bat` במחשב עם Python. נוצר `dist\NetPlan.exe` שאפשר להעתיק לכל מחשב Windows.

### Linux / macOS
```bash
./start.sh                       # מפעיל ופותח את הממשק
./start.sh --install-autostart   # הפעלה אוטומטית עם המחשב
./start.sh --scan                # סריקה חד-פעמית לטרמינל
```
בלינוקס מומלץ `sudo apt install traceroute` כדי לראות את כל הנתבים בדרך.

## פרטיות ואבטחה
- הממשק זמין רק מהמחשב עצמו (127.0.0.1), עם הגנה מפני DNS Rebinding ומפני בקשות מאתרים אחרים.
- כל הנתונים נשמרים מקומית: `%APPDATA%\NetPlan` ב-Windows, `~/.local/share/netplan` בלינוקס, `~/Library/Application Support/NetPlan` במק.
- פניות לאינטרנט: ipinfo.io לזיהוי ה-IP הציבורי (אפשר לכבות בהגדרות), הורדה חד-פעמית של מאגר היצרנים מ-IEEE, ו-Cloudflare בבדיקת מהירות (רק כשמבקשים).
- **השתמש רק ברשתות שבבעלותך או שיש לך אישור לסרוק.**

## מגבלות (חשוב לדעת)
- **"האם הכבל מאובטח":** כבל Ethernet רגיל לא מוצפן אף פעם ברמת הקו. התוכנה אומרת את זה במפורש ובודקת את מה שבאמת מגן עליך: אילו חיבורים מוצפנים, יירוט HTTPS, VPN וזליגות.
- זיהוי סוג המכשיר מבוסס על סימנים (פורטים, יצרן, שמות, UPnP/mDNS), ולכן מוצג עם אחוז ביטחון ואפשר לתקן אותו ידנית.
- טלפונים עם MAC אקראי לא מציגים יצרן; זו הגנת פרטיות של המכשיר.
- רשת גדולה מ-/22 נסרקת לפי ה-/24 של המחשב, או לפי טווח שמגדירים בהגדרות.
- לא נדרשות הרשאות מנהל. בלי הרשאות לא ניתן לזהות שרת DHCP זר באופן אקטיבי, ובלינוקס חלק מבדיקות חומת האש לא זמינות.

## מבנה הקוד
```
netplan.py              הפעלה, הפעלה אוטומטית, מצב טרמינל
netplan_core/
  sysinfo.py            ממשקים, לינק, IP, Gateway, DNS, DHCP (Windows / Linux / macOS)
  discovery.py          Ping, TCP, ARP, NetBIOS, mDNS, SSDP/UPnP, פורטים, באנרים
  classify.py           זיהוי סוג מכשיר וסיכונים
  trace.py              מסלול, NAT כפול, CGNAT, IP ציבורי
  security.py           בדיקות אבטחה וזליגה
  diagnostics.py        תקלות, פתרונות, MTU, DNS, מהירות
  monitor.py            מנוע: זיהוי חיבור כבל, דגימות, סריקות
  store.py              מסד SQLite: רשתות, מכשירים, אירועים
  server.py             שרת מקומי + API + דוח
web/                    הממשק (עברית, RTL, כהה/בהיר, מותאם לנייד)
```
