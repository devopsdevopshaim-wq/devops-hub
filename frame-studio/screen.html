אופטימוס מסך

מסך האולם של האירוע החי, לכל מסך: טלוויזיה, סטרימר, מחשב או מקרן. מחברים פעם אחת בקוד של 6 ספרות, ומשם הכול נשלט מאופטימוס: מה רץ על המסך, תמונות בעלי השמחה, הפס של תמונות האורחים, הודעות על המסך.

⬇️ האפליקציה לטלוויזיה ולסטרימר (APK) 💾 ערכת USB (הכול בתיקייה אחת)

ערכת ה־USB: מחלצים את הקובץ ומעתיקים את התיקייה לדיסק און קי. יש בה את האפליקציה, קובץ הפעלה למחשב Windows ול־Mac, ואת המדריך הזה.

איזה מסך יש לכם?

⭐ הכי מומלץ

📺 Android TV / Google TV

Sony, Philips, TCL, Xiaomi וחלק מ־Hisense. בהגדרות כתוב "Android TV" או "Google TV".

  1. מעתיקים את OptimusScreen.apk לדיסק און קי ומחברים לטלוויזיה.
  2. אם אין בטלוויזיה מנהל קבצים: מתקינים מהחנות File Commander (חינם).
  3. הגדרות ← העדפות מכשיר ← אבטחה והגבלות ← מקורות לא ידועים ← מאשרים את מנהל הקבצים.
  4. פותחים את מנהל הקבצים ← הדיסק און קי ← OptimusScreen.apk ← התקנה.
  5. אם מופיעה אזהרה של Play Protect: "התקן בכל זאת" (האפליקציה לא מהחנות, ולכן האזהרה).
⭐ מתאים לכל טלוויזיה

🔌 סטרימר: Google TV Streamer, Xiaomi TV Stick, Chromecast

לרוב אין להם חיבור USB, אז מורידים ישר מהאינטרנט:

  1. מתקינים מהחנות את האפליקציה Downloader (של AFTVnews, חינם).
  2. מאשרים לה התקנה ממקורות לא ידועים (הגדרות ← אפליקציות ← גישה מיוחדת ← התקנת אפליקציות לא ידועות ← Downloader).
  3. ב־Downloader מקלידים את הכתובת:
    https://github.com/devopsdevopshaim-wq/devops-hub/releases/download/screen-latest/OptimusScreen.apk
  4. מתקינים, ובסוף "מחיקה" של קובץ ההתקנה כדי לפנות מקום.

🔥 Amazon Fire TV Stick

  1. הגדרות ← My Fire TV ← About ← לוחצים 7 פעמים על שם המכשיר (נפתחות אפשרויות מפתחים).
  2. My Fire TV ← Developer options ← Install unknown apps ← Downloader פועל.
  3. מתקינים את Downloader מהחנות של אמזון ומקלידים בה את כתובת ה־APK שלמעלה.

💻 מחשב או לפטופ שמחובר לטלוויזיה / מקרן

  1. מחברים בכבל HDMI ומגדירים במחשב "שכפול מסך" או "מסך שני".
  2. מהדיסק און קי: Windows ← לחיצה כפולה על Optimus-Screen-Windows.cmd. Mac ← Optimus-Screen-Mac.command.
  3. המסך נפתח במסך מלא. יציאה: Alt+F4 (ב־Mac: ⌘+Q).
  4. אם Windows שואל "האם להפעיל": "מידע נוסף" ← "הפעל בכל זאת".
אין התקנה

Samsung / LG / Hisense (VIDAA)

בטלוויזיות האלה אי אפשר להתקין אפליקציה מ־USB: הן מתקינות רק מהחנות של היצרן. שתי דרכים:

  • מומלץ: מחברים אליהן סטרימר (למעלה), וזה עובד בכל טלוויזיה עם HDMI.
  • או: פותחים את הדפדפן של הטלוויזיה בכתובת
    devopsdevopshaim-wq.github.io/devops-hub/frame-studio/tv.html
    זה עובד, אבל הדפדפנים שלהן איטיים יותר, ובחלקן שומר המסך קופץ.

אחרי ההתקנה

  1. פותחים את אופטימוס מסך. על המסך מופיע קוד של 6 ספרות.
  2. באופטימוס במחשב: 🎉 אירוע חי ← 📺 שליטה במסך ← מקלידים את הקוד ← "חיבור".
  3. תוך כמה שניות המסך עובר לאירוע. מכאן הכול נשלט מאופטימוס.

חשוב לדעת

  • צריך אינטרנט במסך. תמונות האורחים מה־QR עוברות דרך השרת. אם ה־Wi-Fi של האולם לא יציב: נקודה חמה מטלפון ייעודי.
  • עדכונים: המסך עצמו מתעדכן לבד מהאתר. את האפליקציה צריך להתקין מחדש רק כשיוצאת גרסה חדשה שלה (נדיר), על אותה התקנה, בלי לאבד את ההגדרות.
  • האפליקציה פותחת רק את מסך האירוע של אופטימוס ולא שום אתר אחר.
