# שיר השירים כסרט: עיבוד קולנועי לכל פרק

לכל פסוק יש שוט עם שחקנים, 117 פסוקים בסך הכול. השוטים נוצרים ב-Veo 3, ובעריכה הפסוק מופיע ככתובית בעברית עם ניקוד וטעמים.

## הליהוק והגישה (`shots.mjs`)
- **השולמית:** צעירה מהרי יהודה, בשמלת פשתן צנועה ובמטפחת. **הדוד:** רועה צעיר עם מקל וגלימה מפוספסת. **בנות ירושלים**, **השומרים**, **שלמה המלך** ו**האחים**.
- בכל שוט התיאור של כל דמות כתוב באותן מילים בדיוק, כדי שהדמויות ייראו אותו דבר לאורך כל הסרט.
- הסרט צנוע ונאמן לאופן שבו קוראים את השיר ביום שישי. האהבה מוצגת דרך מבטים, מרחק, געגוע וטבע, והמגע היחיד הוא אחיזת יד. את תיאורי הגוף מצלמים כדימויים שהם משולים להם: יונים, עדר עזים, פלח רימון ומגדל דויד.
- המראה: אפוס תנכי, עדשות אנמורפיות 35 מ"מ, אור זהוב, תלבושות נאמנות לתקופה. השוטים בלי דיאלוג ובלי מוזיקה, רק צלילי הסביבה.

## הפקה
```
node film/generate.mjs --dry-run              # כמה קטעים ומה העלות המשוערת
node film/generate.mjs --chapter 1 --limit 2  # שני שוטים לבדיקת המראה (צריך GEMINI_API_KEY)
node film/generate.mjs --chapter 1            # כל הפרק
node film/edit.mjs 1                          # עריכה: film/chapters/chapter-1
npx hyperframes render film/chapters/chapter-1 -o renders/film-1.mp4
```
- **עלות:** בסך הכול 134 קטעים של 8 שניות. פסוק ארוך מקבל זווית שנייה. ב-$0.40 לשנייה זה בערך $430 לכל 8 הפרקים, ובערך $60 לפרק א'. המודל המהיר, `--model veo-3.0-fast-generate-001`, זול יותר. המחירים משתנים, אז כדאי לבדוק את המחיר העדכני לפני ההפקה.
- הסקריפט מדלג על קטעים שכבר קיימים, ולכן אפשר לעצור אותו ולהמשיך מאותה נקודה.
- **בעריכה:** כל קטע מואט עד 0.65x כדי להתאים לאורך הפסוק. בין השוטים יש מעבר רך, והמצלמה מתקרבת לאט. הכתובית מופיעה בתחתית המסך. הסרט נפתח בכותרת זהב ונסגר במסך שחור.
- **קריינות:** שמים את `audio/chapter-N.wav` ואת קובץ התזמון, והסרט מסתנכרן לקריאה. צלילי הסביבה של השוטים יורדים אז לעוצמה נמוכה.
