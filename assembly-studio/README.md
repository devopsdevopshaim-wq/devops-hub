# מכלול — סטודיו הרכבה

אתר בעברית שמקבל קבצי SolidWorks ותיאור של המערכת שרוצים לבנות, ומכין מהם:

- **תכנית הרכבה** שלב אחרי שלב: חלקים לכל שלב, הוראות, מחברים, מומנטי הידוק, בדיקה בסוף כל שלב, כלים ובטיחות.
- **סרטוני הרכבה**: אנימציה שבה כל חלק נכנס למקומו לפי סדר התכנית, עם כתוביות. מקליטים סרטון מלא או סרטון לכל שלב ומורידים כ-WebM.
- **שרטוטים** בגודל A3 עם טבלת כותרת: מבטי חזית, צד, על ואיזומטרי עם מידות כלליות, מבט מפוצץ עם בלונים ורשימת חלקים, וגיליון לכל שלב עם חץ הכנסה.
- **תיק הרכבה** מלא (PDF, HTML או Word): שער, רשימת חלקים, שרטוטים, כלים ובטיחות, שלבים עם שורת חתימה, **חלקי חילוף מומלצים** (בלאי, קריטיים, מתכלים, מחברים) עם כמות למלאי ותדירות, תחזוקה מונעת וטבלת מסירה.
- **משימה חדשה לכל תכנית**: כל תכנית שנוצרת פותחת משימה בלוח המשימות, עם תת-משימה לכל שלב. אפשר לפתוח במקביל גם Issue ב-GitHub.

## אילו קבצים אפשר להעלות

| קובץ | מה האתר עושה איתו |
| --- | --- |
| `SLDASM` + `SLDPRT` | **נפתחים ישירות, בלי SolidWorks.** האתר קורא את עץ הרכיבים, הכמויות והמיקום של כל חלק, ומציג את המכלול בתלת-ממד. מעלים את המכלול יחד עם כל קבצי החלקים שלו. |
| `SLDPRT` לבד | חלק בודד בתלת-ממד, עם המידות ותמונת התצוגה. |
| `PDF` / `SLDDRW` / תמונה | **שרטוט לניתוח.** כל עמוד הופך לתמונה, והטקסט נשלף מה-PDF. בשלב 3 Claude קורא את טבלת הכותרת, טבלת החלקים, הבלונים, המידות וההערות, ובונה רשימת חלקים ותכנית הרכבה, גם כשאין מודל. |
| `STEP` / `IGES` / `STL` / `OBJ` / `GLB` | תלת-ממד ורשימת חלקים מהמכלול. |

**קבצי SolidWorks מגרסה 2015 ומעלה** נקראים במלואם: רשתות התצוגה השמורות בקובץ, המיקומים ועץ הרכיבים. רכיבים מספריית Toolbox (ברגים ואומים) שאין להם רשת שמורה נכנסים לרשימת החלקים עם הכמות שלהם. **קבצים ישנים** (לפני 2015) נפתחים חלקית: תמונת תצוגה ושמות רכיבים. לתלת-ממד מלא שומרים אותם כ-STEP.

הקורא של SolidWorks (`js/solidworks.js`) הוא מימוש ב-JavaScript שנכתב לפי [sldprt-export](https://github.com/XRTC5/sldprt-export) (רישיון MIT) ומפרט הפורמט של cadmpeg (CC BY 4.0).

## הפעלה

### עם Claude (מומלץ)

צריך Node.js 18 ומעלה ומפתח API של Anthropic.

```bash
cd assembly-studio
npm install
ANTHROPIC_API_KEY=sk-ant-... npm start
```

ואז פותחים את `http://localhost:8788`.

Claude מקבל את רשימת החלקים עם המידות והמיקום של כל חלק במכלול, ותמונה של המודל. לפי זה הוא קובע סדר הרכבה שאפשר לבצע בפועל. המפתח נשמר רק בשרת.

| משתנה | מה הוא עושה |
| --- | --- |
| `PORT` | פורט השרת (ברירת מחדל 8788) |
| `ASM_MODEL` | המודל (ברירת מחדל `claude-opus-5-5`) |
| `ACCESS_CODE` | קוד גישה שהאתר מבקש לפני שימוש ב-AI. חובה אם השרת פתוח לאינטרנט. |
| `GITHUB_TOKEN` + `GITHUB_REPO` | אופציונלי: מאפשר לפתוח Issue ב-GitHub לכל תכנית (`GITHUB_REPO` בפורמט `owner/repo`). |

### בלי שרת

פותחים את https://devopsdevopshaim-wq.github.io/devops-hub/assembly-studio/ . כל האתר עובד בדפדפן: תלת-ממד, סרטונים, שרטוטים ותיק הרכבה. לתכנית יש שתי אפשרויות:

- **תכנית בסיסית אוטומטית**: נבנית מיד לפי גודל ומיקום החלקים. הבסיס הוא החלק הנמוך והרחב ביותר, והברגים מצורפים לחלק הקרוב אליהם.
- **Claude בהעתק-הדבק**: מעתיקים את ההנחיה ל-Claude.ai ומדביקים את התשובה.

## שמירה ופרטיות

הפרויקטים, הקבצים, הסרטונים, השרטוטים והמשימות נשמרים רק בדפדפן (IndexedDB). הקבצים לא נשלחים לשום שרת. ל-Claude נשלחים רק רשימת החלקים, עמודי השרטוט ותמונת מבט על המודל, ורק כשלוחצים על יצירת תכנית.

## קבצים

| קובץ | תפקיד |
| --- | --- |
| `index.html` | מבנה האתר |
| `css/styles.css` | עיצוב |

| `js/viewer.js` | תלת-ממד (Three.js, ו-OpenCascade לקבצי STEP), אנימציה, הקלטת וידאו ושרטוטים |
| `js/doc.js` | בניית תיק ההרכבה וקבצי CSV |
| `js/store.js` | שמירה מקומית |
| `js/app.js` | ממשק המשתמש, התכנית ולוח המשימות |
| `server.mjs` | שרת: מגיש את האתר, מעביר בקשות ל-Claude ופותח Issues ב-GitHub |

## מגבלות

- השרטוטים הם שרטוטי הרכבה והסבר. הם לא מחליפים שרטוטי ייצור עם טולרנסים מ-SolidWorks.
- מומנטי ההידוק ש-Claude מציע הם ערכים מקובלים. צריך לאמת אותם מול מפרט היצרן.
- הקלטת הסרטונים דורשת Chrome או Edge, ורצה בזמן אמת.
