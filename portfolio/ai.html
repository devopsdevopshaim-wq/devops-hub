מודלי AI

כל המודלים שיש לך במקום אחד, רק במסך הזה: המקומיים שרצים אצלך במחשב (Ollama, Open WebUI, OpenClaw) והענן (Gemini, ChatGPT, DeepSeek, Claude). אפשר לבדוק חיבור, לטעון את רשימת המודלים, לשלוח שאלה לאחד, או לשלוח אותה לכמה ולהשוות. המפתחות נשמרים רק בדפדפן הזה (localStorage), לא בשרת ולא בגיטהאב, ויוצאים רק אל הספק עצמו.

מעבדת בדיקות

איך מחברים את המודלים שבמחשב

הדפדפן פונה למודל המקומי ישירות מהמחשב שלך, ולכן צריך לאפשר לאתר הזה לפנות אליו (CORS), ובכרום לאשר "גישה לרשת המקומית" כשהוא שואל.

Ollama (ברירת מחדל http://localhost:11434): מפעילים אותו עם OLLAMA_ORIGINS=https://devopsdevopshaim-wq.github.io. ב־Windows: הגדרת משתנה סביבה ואז הפעלה מחדש של Ollama. ב־Docker: -e OLLAMA_ORIGINS=https://devopsdevopshaim-wq.github.io.

Open WebUI (http://localhost:3000): משתנה CORS_ALLOW_ORIGIN=https://devopsdevopshaim-wq.github.io, ומפתח API מתוך: הגדרות ← חשבון ← מפתחות API.

OpenClaw (ברירת מחדל http://127.0.0.1:18789): צריך שה־gateway יחשוף נקודת קצה תואמת OpenAI (/v1/chat/completions) ויאפשר את האתר ב־CORS; הטוקן נכנס לשדה המפתח. אם אצלך הכתובת או הנתיב שונים, משנים בכרטיס.

בסאפארי ודפדפנים שחוסמים פנייה מ־https אל http מקומי זה לא יעבוד. משתמשים בכרום, אדג' או פיירפוקס.
