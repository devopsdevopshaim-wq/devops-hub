הוספת פרויקט

יש פרויקט חדש? זה לוקח דקה

מה מוסיפים?
  1. פתחו מאגר חדש ב־GitHub. תנו לו שם באנגלית, סמנו Public ולחצו Create repository.
  2. בעמוד שנפתח לחצו על uploading an existing file, גררו את קובץ ה־HTML (ואת הקבצים שלידו), ולחצו Commit changes. אם הקובץ לא נקרא index.html, שנו את שמו ל־index.html.
  3. במאגר: Settings ← Pages ← Branch: main ← Save.
  4. העתיקו את כתובת המאגר לשדה למטה, בחרו "מאגר GitHub", ושלחו.

נפתח עמוד ב־GitHub עם כל הפרטים. לוחצים שם Create, ותוך 2–3 דקות הפרויקט באתר, עם צילום מסך. רק בעל המאגר יכול להוסיף.
