סיסמת מנהל

העמוד הזה אופציונלי. הדרך הרגילה: בעמוד הכניסה לוחצים "קבלת סיסמה ראשונית למייל", נכנסים איתה ובוחרים סיסמה משלכם. הסיסמה כאן היא דרך חזרה למקרה שהמייל לא זמין: כשמשנים את הסוד ADMIN_PASSWORD ומריצים את ההתקנה, היא הופכת לסיסמת המנהל.

הסיסמה נוצרת כאן, בדפדפן שלך בלבד. היא לא נשלחת לשום מקום ולא נשמרת. אף אחד אחר לא רואה אותה, גם לא אני.

הסיסמה שלך:

  1. שמרו אותה עכשיו במנהל סיסמאות או במקום בטוח. אחרי שתסגרו את העמוד אי אפשר לראות אותה שוב, ובשרת נשמרת רק גרסה מוצפנת שלה.
  2. פתחו את יצירת סוד חדש ב־GitHub (פותח בלשונית חדשה).
  3. בשדה Name כתבו בדיוק: ADMIN_PASSWORD
  4. בשדה Secret הדביקו את הסיסמה, ולחצו Add secret. (סוד נפרד: לא נוגעים בסוד SPIDER הקיים.)
  5. חזרו אליי ותכתבו "הוספתי". אני מריץ את ההתקנה ובודק שהכניסה עובדת.

לשינוי הסיסמה בעתיד: יוצרים סיסמה חדשה כאן, מחליפים את הערך של הסוד ADMIN_PASSWORD ומריצים שוב את ההתקנה.
