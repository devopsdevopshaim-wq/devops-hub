# פארק־פלאן — מתכנן חניון רובוטי

אתר בעברית לתכנון מעשי של חניון רובוטי (מעלית + שאטל בכל קומה + מסובבת בלובי).
מזינים קומות, תאים, מידות ומשקל רכב, מהירויות וחיישני גובה, והאתר מחשב ומציג:

- קומות, מפלסים, גובה נקי לכל קומה ומספור תאים
- מעליות, שאטלים, מסובבת: הספק מנוע, זרם, רמפות ויחס תמסורת
- ארונות פיקוד: כמה דרייברים ומנועים בכל ארון, על מה הוא שולט, כרטיסי IO, מידות ארון
- רשת PROFINET: כתובת IP ושם התקן לכל מעלית, שאטל, מסובבת ו‑IO
- פרמטרי SINAMICS G120 לכל סוג ציר בקבוצות (מנוע, רמפות, בקרה, בלם, תקשורת, EPos, Safety) והגדרות SINA_POS/SINA_SPEED
- חיישנים ו‑IO: תג, כתובת, מהדק ומיקום, כולל חיישני גלישה ובדיקות לובי
- תוכנת PLC (S7‑1500F / TIA Portal): מבנה בלוקים, טבלת תאים וקוד SCL לרצף אחסון
- תבניות PLC מוכנות לייבוא (UDT/FB/FC/DB + טבלת תגיות): תא, שאטל, מעלית, מסובבת, לובי, העברת מגש ומשימה. משנים כמות תאים/קומות/מעליות והקבצים משתכפלים לבד; אפשר לבטל תאים בודדים
- דגם חיישן גלישה לבחירה (SICK WS/WE34, Banner QS30, Leuze LS46C) עם בדיקת טווח
- הרכבה וחיווט: סדר עבודה, תוכנית מהדקים לכל ארון, טבלת כבלים
- שרטוטים (SVG): תוכנית קומה, חתך, פרט חיישן גלישה, חזית ארון, חד‑קווי, רשת, לובי, שאטל, מעלית, מסובבת, תא, חיווט חיישנים ומעגל הנעה
- הדמיה של אחסון ושליפה
- דוח טקסט ו‑CSV להעתקה למייל, והדפסה של כל התכנון

## אתר התצוגה ליזמים

בראש הדף: הדמיית החניון (תמונות ב‑`img/`, מרונדרות מהמודל התלת־ממדי של האתר), איך זה עובד, הדמיה תלת־ממדית חיה,
נתונים ליזם, ארבע תצורות לדוגמה שנטענות למתכנן, גלריית פרויקטים ויצירת קשר.

### גלריה והעלאת תמונות

- תמונות שפורסמו: `gallery/gallery.json` (+ קבצי התמונות באותה תיקייה, או `url` לתמונה ב‑`img/`).
- העלאה באתר הציבורי: התמונה נשמרת בדפדפן ומסומנת "ממתין לפרסום". "פרסום באתר" שומר אותה במאגר דרך GitHub API
  (צריך Fine‑grained token עם Contents: Read and write למאגר devops-hub, נשמר רק בדפדפן), והאתר מתעדכן לבד.
- בקישור הפרטי ב‑Claude התמונות נשמרות באחסון של הקישור.

## הדמיית ארון תלת־ממדית

לשונית "ארון – הדמיה 3D": הארון נבנה מאותו תכנון של לשונית החיווט, ב‑11 שלבי הרכבה עם הוראות וכלים. three.js נטען מ‑cdnjs רק כשפותחים הדמיה.

## הרצה

פותחים את `index.html` בדפדפן. אין שרת ואין התקנה. ההגדרות נשמרות בדפדפן.

## עריכה

עורכים את `app.html` (מקור הארטיפקט) ומריצים `./build.sh` כדי לבנות מחדש את `index.html`.

## הערה

זה תכנון ראשוני. לפני רכש והתקנה נדרש אישור של מהנדס חשמל ובודק בטיחות
(EN 14010, EN ISO 13849‑1, EN 60204‑1, EN 81‑20 והתקנים המקומיים).
