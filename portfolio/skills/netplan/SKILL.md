# נט־פלאן — תכנון רשתות תקשורת

מגדירים מבנה, קומות וחדרים, ומקבלים תכנית תקשורת מלאה: כתובת IP ו-VLAN לכל שקע, ארונות ומתגים, הגדרות מוכנות לציוד, ניטור וסטטיסטיקות.

- כתובת: https://devopsdevopshaim-wq.github.io/devops-hub/netplan/
- קוד: https://github.com/devopsdevopshaim-wq/devops-hub
- הקוד יושב בתיקייה `netplan/` במאגר https://github.com/devopsdevopshaim-wq/devops-hub
- תחום: DevOps ואירוח
- עמוד הפרויקט בתיק העבודות: https://devopsdevopshaim-wq.github.io/devops-hub/portfolio/#p/netplan

## מה הוא יודע לעשות

- כתובת IP, מסכה, Gateway ו-VLAN לכל שקע בכל חדר
- שרטוט בניין, ארונות, מתגים ומפת פורטים
- הגדרות Cisco ושרת DHCP מוכנות להטמעה
- סקופ ניטור צריכת נתונים, סטטיסטיקות והדפסה

## איך זה בנוי

- טכנולוגיות: HTML, JavaScript, SVG, Cisco IOS-XE, ISC Kea

## איך משנים ומפרסמים

- מורידים את המאגר: `git clone https://github.com/devopsdevopshaim-wq/devops-hub.git` ועובדים בתיקייה `netplan/`.
- כל שינוי שנדחף ל־main מתפרסם לבד ל־GitHub Pages תוך כ־2 דקות (Action: Deploy vacation-hub to GitHub Pages).
- לפני כל שינוי קוראים את הקבצים עצמם. הרשימות כאן הן תקציר, לא תחליף לקוד.

## למה זה נבנה

רציתי שתכנון רשת לבניין שלם ייקח דקות ולא שבועות: מגדירים קומות וחדרים, ומקבלים תכנית שאפשר להדפיס, להטמיע ולנטר.
