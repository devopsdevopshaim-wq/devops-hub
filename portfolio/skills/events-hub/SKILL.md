# פריים אירועים — אפליקציה לאירועים

שתי אפליקציות: ללקוח ולמנהל. באירוע האורחים סורקים QR, עורכים תמונות עם AI ואנימציות ושולחים להדפסה. אחרי האירוע האפליקציה נשארת בטלפון כחנות מתנות וחבילות לאירועים, עם שיוך אוטומטי של ספק ושליח לפי עיר ומעקב משלוחים.

- כתובת: https://devopsdevopshaim-wq.github.io/devops-hub/events-hub/
- קוד: https://github.com/devopsdevopshaim-wq/devops-hub
- תחום: אתרים ומערכות
- עמוד הפרויקט בתיק העבודות: https://devopsdevopshaim-wq.github.io/devops-hub/portfolio/#p/events-hub

## מה הוא יודע לעשות

- QR לכל אירוע: מכסת תמונות לאורח ועד 3 אפשרויות הדפסה (מגנט, בלוק, מסגרת קרטון)
- עורך תמונות: פילטרים, אפקטי AI, טקסט, מדבקות, מסגרות ואנימציות
- חנות: מגנטים, בלוקים, חבילות חינה, חתונה ומקווה, וקולקציות לחגים ולכנסים
- ספקים לפי תחום ושליחים לפי עיר, עם שיוך אוטומטי להזמנה
- מעקב משלוח עם זמנים, זיהוי משלוח תקוע והערות
- תשתית סליקה מאובטחת וקיצור דרך לחברת הסליקה

## איך זה בנוי

- טכנולוגיות: JavaScript, Cloudflare Workers, Durable Objects, PWA

## איך משנים ומפרסמים

- מורידים את הקוד: `git clone https://github.com/devopsdevopshaim-wq/devops-hub.git`
- עורכים, ודוחפים ל־main. GitHub Pages מעדכן את האתר תוך דקה בערך.
- לפני כל שינוי קוראים את הקבצים עצמם. הרשימות כאן הן תקציר, לא תחליף לקוד.

## למה זה נבנה

רציתי שהאורח ייקח מהאירוע יותר ממגנט אחד: אפליקציה שנשארת אצלו בטלפון, עם התמונות שלו וחנות שממשיכה ללוות אותו לאירוע הבא.

- עונים בעברית, אלא אם המשתמש כותב בשפה אחרת.
- לא ממציאים יכולות שלא מופיעות כאן או בקוד. אם לא יודעים, אומרים, ומציעים לבדוק בקוד.
