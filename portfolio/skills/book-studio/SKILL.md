# ספר — סטודיו לכתיבת ספרים אתר בעברית שהופך את הסיפור שלכם לספר קריאה מקצועי. מספרים במילים פשוטות, בלי הגבלת אורך, ו-Claude מנסח את הטקסט בשפה ספרותית גבוהה. האתר מעמד את הספר לעמודים אמיתיים בגודל דפוס, עם תמונות ואיורים, ומוציא קובץ PDF מוכן להדפסה. ## איך זה עובד | שלב | מה עושים | | --- | --- | | 1. פרטי הספר | שם, מחבר, סוגה (ממואר/דוקו, ביוגרפיה, דרמה, רומנטי, מתח, היסטורי, פנטזיה, השראה, ספר ילדים), קול מספר, משלב לשוני, אורך (24 עד 450 עמודים או כל מספר אחר) וגודל הספר המודפס. | | 2. הסיפור שלך | כותבים חופשי בקטעים, בלי הגבלת מילים. אפשר גם לייבא קבצי טקסט או להקליט בקול (הקלדה קולית בעברית). | | 3. תמונות וציורים | מעלים צילומים ובוחרים איפה כל אחד יופיע: בפתיחת פרק, בסופו, בעמוד מלא או על הכריכה. כל צילום אפשר להפוך לציור בעבודת יד (רישום עיפרון, פחם בספיה, צבעי מים, ציור שמן). ההמרה נעשית כולה בדפדפן, והצילום לא נשלח לשום מקום. אפשר גם להזמין ציור חדש מתיאור במילים (צבעי מים, שמן, עיפרון, פחם, דיו, גואש לילדים), או ציור לכל הפרקים בלחיצה אחת בשלב 4. | | 4. כתיבת הספר | Claude בונה מבנה פרקים שמתאים לאורך שבחרתם, ואז כותב פרק אחרי פרק. כל פרק אפשר לערוך ביד, להמשיך או לשכתב לפי הערה. | | 5. הספר המוכן | ארבעה סגנונות עיצוב יוקרתיים לבחירה: **מלכותי** (זהב על כחול לילה)
