# מתאר — תכנון פנים

מקבל את נתוני הדירה והמשפחה ומחזיר תכנון ריהוט מלא, עם סיור תלת־ממדי ורשימת קניות.

- כתובת: https://devopsdevopshaim-wq.github.io/devops-hub/interior/
- קוד: https://github.com/devopsdevopshaim-wq/devops-hub
- הקוד יושב בתיקייה `interior-hub/` במאגר https://github.com/devopsdevopshaim-wq/devops-hub
- תחום: אתרים ומערכות
- עמוד הפרויקט בתיק העבודות: https://devopsdevopshaim-wq.github.io/devops-hub/portfolio/#p/interior

## מה הוא יודע לעשות

- תוכנית קומה עם מידות
- סיור תלת־ממדי 360°
- רשימת רהיטים והערכת תקציב
- חנויות בישראל עם טלפון וקישור ל־Waze

## איך זה בנוי

- טכנולוגיות: Three.js, JavaScript, WebGL

## איך משנים ומפרסמים

- מורידים את המאגר: `git clone https://github.com/devopsdevopshaim-wq/devops-hub.git` ועובדים בתיקייה `interior-hub/`.
- כל שינוי שנדחף ל־main מתפרסם לבד ל־GitHub Pages תוך כ־2 דקות (Action: Deploy vacation-hub to GitHub Pages).
- לפני כל שינוי קוראים את הקבצים עצמם. הרשימות כאן הן תקציר, לא תחליף לקוד.

## למה זה נבנה

תכנון דירה חדשה מתחיל בדרך כלל בדף ריק. מתאר נותן נקודת פתיחה מלאה שאפשר להסתובב בה.

## כללים

- עונים בעברית, אלא אם המשתמש כותב בשפה אחרת.
- לא ממציאים יכולות שלא מופיעות כאן או בקוד. אם לא יודעים, אומרים, ומציעים לבדוק בקוד.
- מי שמעוניין במערכת כזו לעסק שלו: אפשר לפנות לבעל הפרויקט דרך עמוד השירותים https://devopsdevopshaim-wq.github.io/devops-hub/portfolio/services.html
