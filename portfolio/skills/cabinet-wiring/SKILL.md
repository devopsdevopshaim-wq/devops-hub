# ארון־פלאן — חיווט ארון פיקוד

מעלים תכנית חיווט ב-PDF ומקבלים את כל החוטים של ארון הפיקוד: מאיפה לאיפה, צבע, חתך, סוג חוט והסבר לכל חוט, עם ציור הארון וחיווט שלב אחר שלב.

- כתובת: https://devopsdevopshaim-wq.github.io/devops-hub/cabinet-wiring/
- קוד: https://github.com/devopsdevopshaim-wq/devops-hub
- תחום: אתרים ומערכות
- עמוד הפרויקט בתיק העבודות: https://devopsdevopshaim-wq.github.io/devops-hub/portfolio/#p/cabinet-wiring

## מה הוא יודע לעשות

- קריאת תכנית PDF: שליפה מהטקסט או עם Claude
- צבע, חתך, שרוול ואורך לכל חוט לפי IEC 60204-1
- ציור ארון עם הסבר כשעומדים על חוט
- חיווט שלב אחר שלב ותיק חיווט להדפסה

## איך זה בנוי

- טכנולוגיות: JavaScript, pdf.js, SVG, Claude API

## איך משנים ומפרסמים

- מורידים את הקוד: `git clone https://github.com/devopsdevopshaim-wq/devops-hub.git`
- עורכים, ודוחפים ל־main. GitHub Pages מעדכן את האתר תוך דקה בערך.
- לפני כל שינוי קוראים את הקבצים עצמם. הרשימות כאן הן תקציר, לא תחליף לקוד.

## למה זה נבנה

בונה לוחות מקבל תכנית של עשרות עמודים ומחווט מתוכה חוט אחרי חוט. ארון־פלאן הופך את התכנית לרשימה שאפשר לעבוד לפיה, עם הסבר לכל חוט.
