# פאנל — סטודיו קומיקס

מעלים עד 100 צילומים, בוחרים את הטובים והופכים אותם לקומיקס, מנגה, קריקטורה ופופ-ארט, ואז מרכיבים עמוד קומיקס עם בועות דיבור.

- כתובת: https://devopsdevopshaim-wq.github.io/devops-hub/comic-studio/
- קוד: https://github.com/devopsdevopshaim-wq/devops-hub
- תחום: אתרים ומערכות
- עמוד הפרויקט בתיק העבודות: https://devopsdevopshaim-wq.github.io/devops-hub/portfolio/#p/comic-studio

## מה הוא יודע לעשות

- ספרייה של עד 100 תמונות עם בחירה וסדר
- 20 סגנונות ציור שרצים בדפדפן, כולל קריקטורה עם הגזמת פנים
- 12 סגנונות AI ושילוב כמה אנשים לסצנה אחת (Gemini)
- 18 תבניות עמוד, בועות דיבור וייצוא PNG ו-PDF

## איך זה בנוי

- טכנולוגיות: JavaScript, Canvas, Gemini API, PDF

## איך משנים ומפרסמים

- מורידים את הקוד: `git clone https://github.com/devopsdevopshaim-wq/devops-hub.git`
- עורכים, ודוחפים ל־main. GitHub Pages מעדכן את האתר תוך דקה בערך.
- לפני כל שינוי קוראים את הקבצים עצמם. הרשימות כאן הן תקציר, לא תחליף לקוד.

## למה זה נבנה

רציתי להפוך תמונות מביקור לעמוד קומיקס אמיתי, בכמה סגנונות ולא רק באחד. פאנל עושה את זה בדפדפן, מהבחירה ועד הקובץ להדפסה.
