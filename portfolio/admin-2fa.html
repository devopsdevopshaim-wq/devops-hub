אימות דו־שלבי למנהל

כך הכניסה שלך כמנהל נעשית בטוחה באמת: בנוסף לקוד שמגיע למייל, צריך גם קוד שמשתנה כל 30 שניות באפליקציה בטלפון שלך. מי שיפרוץ את המייל עדיין לא יוכל להיכנס.

המפתח נוצר כאן, בדפדפן שלך בלבד. הוא לא נשלח לשום מקום ולא נשמר, ואף אחד אחר לא רואה אותו (גם לא אני). לכן לא מומלץ לצלם אותו או לשלוח אותו בצ׳אט.

המפתח שלך:

האותיות A–Z והספרות 2–7, בלי רווחים.

  1. באפליקציית האימות בטלפון (Google Authenticator, Microsoft Authenticator או Authy): הוספת חשבון ← הזנת מפתח ידנית. שם: SPIDER, מפתח: המפתח שלמעלה, סוג: מבוסס זמן.
  2. בדיקה שהכול תקין: הקלידו כאן את הקוד שהאפליקציה מציגה.
  3. ב־GitHub: Settings ← Secrets and variables ← Actions ← הסוד SPIDER, מוסיפים שורה חדשה (במקום XXXX המפתח עצמו): ADMIN_TOTP_SECRET=XXXX
  4. מריצים שוב את ההתקנה (Actions ← Deploy agents to n8n Cloud ← Run workflow). מעכשיו הכניסה כמנהל דורשת גם קוד מהאפליקציה.

חשוב: שמרו את המפתח גם במקום בטוח אחר (למשל מנהל סיסמאות), למקרה שהטלפון ילך לאיבוד. אם ננעלתם בחוץ, מוחקים את השורה מהסוד ומריצים את ההתקנה שוב.
