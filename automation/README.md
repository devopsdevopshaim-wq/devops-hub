# דרייב־פלאן: ממירי תדר ומתקנים אוטומטיים

באוויר (אחרי מיזוג ל-main): https://devopsdevopshaim-wq.github.io/devops-hub/automation/

מערכת לתכנון, הגדרה וניטור של ממירי תדר (VFD) שמנוהלים בתקשורת, בלי תלות ביצרן. מגדירים מתקן ורשימת מנועים, ובוחרים יצרן, פרוטוקול ובקר. המערכת מחשבת ומפיקה את כל השאר.

## האפשרויות

- **17 יצרני ממירים** ו"ממיר כללי": ‏ABB, ‏Siemens, ‏Danfoss/Vacon, ‏Schneider, ‏Yaskawa, ‏Mitsubishi, ‏Delta, ‏Rockwell, ‏WEG, ‏Lenze, ‏Fuji, ‏Invertek, ‏Hitachi, ‏LS, ‏INVT ו-Omron. אפשר להגדיר יצרן שונה לכל מנוע.
- **9 פרוטוקולים:** Modbus RTU, ‏Modbus TCP, ‏PROFINET, ‏EtherNet/IP, ‏EtherCAT, ‏PROFIBUS DP, ‏CANopen, ‏BACnet/IP ו-BACnet MS/TP.
- **10 פלטפורמות בקר:** IEC 61131-3 כללי (CODESYS), ‏Siemens TIA, ‏Rockwell Studio 5000, ‏Schneider Machine Expert, ‏Omron Sysmac, ‏Mitsubishi GX Works3, ‏Beckhoff TwinCAT, ‏ABB AC500, ‏Unitronics ו-Delta.
- **9 סוגי עומס:** משאבה, מפוח, מדחס, מסוע, מערבל, עגורן, אקסטרודר, צנטריפוגה וכללי.
- **6 תבניות מתקן:** תחנת שאיבה, HVAC, קו ייצור, מט״ש, עגורן גשר וחדר מדחסים.

## מה מקבלים

| מסך | תוכן |
| --- | --- |
| ממירים וחשמל | גודל ממיר בעומס רגיל או כבד, סדרה מתאימה אצל היצרן, ממשק תקשורת (מובנה, כרטיס או Gateway), נתיכים, כבל הזנה, כבל מנוע מסוכך, ומשנקים, מסנני EMC, du/dt וסינוס ונגד בלימה לפי הצורך. בנוסף: סיכום kVA, שנאי, פיזור חום ואוורור, הרמוניות, תרשים חד־קווי, והשוואה בין כל היצרנים לכל מנוע. |
| פרמטרים | גיליון של 20 ערכים לכל ממיר, עם מספרי הפרמטרים אצל היצרן (ABB, ‏Siemens, ‏Danfoss, ‏Schneider, ‏Yaskawa, ‏Mitsubishi, ‏Delta, ‏Rockwell, ‏WEG). אפשר להציג את הגיליון לפי יצרן אחר לצורך השוואה. |
| תקשורת | IP, שם PROFINET, ‏Slave/Node/MAC וקווי RS-485, ציוד רשת, זמני מחזור ועומס אפיק, ומפת נתונים: PROFIdrive Telegram 1, ‏ODVA 21/71, ‏CiA 402 ומפות Modbus של היצרנים. כולל שרטוט טופולוגיה. |
| קוד בקר | בלוקי Structured Text לפרופילים PROFIdrive, ‏CiA 402, ‏ODVA ו-Modbus, מופע לכל ממיר, ורשימת תגים. |
| לוח בקרה | הדמיית HMI: הפעלה, עצירה, מהירות, איפוס, ומילת הפיקוד שנשלחת. מוצגים זרם, הספק, טמפרטורה ומגמה, ואפשר להדמות תקלות. |
| חיסכון באנרגיה | חישוב לפי חוקי הדמיון במשאבות ובמפוחים, לעומת ויסות מכני: kWh, ‏₪ ו-CO₂. |
| הדפסה | תיק מתקן: ציוד, חשמל, תרשים חד־קווי, גיליונות פרמטרים עם תיבות סימון, תקשורת, אנרגיה וקוד. |

## חשוב

מספרי הפרמטרים, המודולים ומפות הרגיסטרים לקוחים מהדורות הנפוצות של כל סדרה. הם עשויים להשתנות בין דגמים וגרסאות קושחה. לפני הזנה בשטח יש לאמת מול מדריך היצרן, ומהנדס צריך לאשר את חישובי ההגנות והכבלים לפי התקנים החלים.
