# מסע — מערכת לניהול חופשות

אתר לתכנון וניהול חופשות בארץ ובחו״ל, בעברית, עובד מכל דפדפן ובלי התקנה.

## הפעלה

**הדרך הכי פשוטה:** לחיצה כפולה על `index.html`. האתר נפתח בדפדפן ועובד מיד.

**עם שרת מקומי** (מומלץ, כדי שהמפות והתמונות ייטענו בצורה חלקה):

```bash
cd vacation-hub
npx serve .          # או: python3 -m http.server 8080
```

ואז פותחים את הכתובת שמופיעה (למשל `http://localhost:3000`).

**כתובת אינטרנט קבועה (GitHub Pages):** בריפו יש כבר workflow שמעלה את האתר. פעם אחת: Settings → Pages → Source: **GitHub Actions**. מאותו רגע כל שינוי ב-`vacation-hub` שנכנס ל-`main` מתפרסם אוטומטית בכתובת `https://<שם-המשתמש>.github.io/devops-hub/`.

אפשר גם להעלות את התיקייה כמו שהיא ל-Netlify או Vercel. אין צורך בשלב build.

> בפתיחה ישירה של הקובץ (לחיצה כפולה) הסרטונים נפתחים ב-YouTube. מאתר אינטרנט (GitHub Pages או שרת מקומי) הם מתנגנים בתוך העמוד.

## מה יש באתר

| אזור | מה עושים שם |
| --- | --- |
| תכנון לפי תאריכים | מסמנים ביומן יציאה וחזרה. האתר מדרג את היעדים לפי מזג האוויר, העונה ואורך החופשה, מציג כמה ימי עבודה צריך לקחת וחגים בתקופה, ומחשב עלות משוערת. |
| יעדים | 14 יעדים (אילת, ירושלים, תל אביב, הגליל, פריז, לונדון, רומא, ברצלונה, אתונה, פראג, ניו יורק, דובאי, בנגקוק, טוקיו). |
| עמוד יעד | סקירה ומזג אוויר, טיסה ושדה תעופה, מלונות, השכרת רכב, מסעדות כשרות / מישלן / מקומיות, תחבורה ציבורית ועלויות, מסלולי טיול, מפה אינטראקטיבית, סרטונים. |
| זמני שדה תעופה | שעת טיסה ועיר יציאה, ומתקבל לוח זמנים: מתי לצאת מהבית, מתי נסגר הצ׳ק-אין, מתי נוחתים בשעון המקומי ומתי מגיעים למלון. |
| מחשבון עלויות | פירוט לפי טיסות, לינה, רכב, אוכל, תחבורה ואטרקציות. אפשר לערוך כל שורה. |
| החופשות שלי | חופשות שמורות עם ספירה לאחור, תקציב, רשימת הכנות, הערות, והוספה ליומן Google. |
| עזרה ותמיכה | מדריך, שאלות נפוצות, מספרי חירום ועוזר צ׳אט שעונה על שאלות (כפתור "צריכים עזרה?" בכל עמוד). |

**תמונות וסרטונים אמיתיים:** לכל יעד 3 תמונות מ-Wikimedia Commons (לשונית "תמונות", עם קישור לצלם ולרישיון) ו-3 סרטוני YouTube של מטיילים ויוצרי תוכן אמיתיים (לשונית "סרטונים וממליצים", ובדף הבית "מטיילים ממליצים"). הרשימות נמצאות ב-`js/media.js`.

כל כפתורי ההזמנה (Skyscanner, Google Flights, Kayak, Booking, Airbnb, Expedia ועוד) נפתחים עם היעד והתאריכים שבחרתם כבר ממולאים.

## הוספה או עריכה של יעד

כל המידע נמצא בקובץ אחד: `js/data.js`. מעתיקים יעד קיים, משנים את הפרטים (שם, מחירים, מלונות, מסעדות, מסלולים, נקודות במפה, צבעי הפוסטר) ושומרים. היעד מופיע אוטומטית בכל האתר.

## מבנה הקבצים

```
vacation-hub/
├── index.html          דף האתר
├── css/styles.css      העיצוב (כולל מצב כהה)
├── js/data.js          נתוני היעדים, חגים ואתרי הזמנה
├── js/media.js         תמונות וסרטונים לכל יעד
├── js/posters.js       איורי הכרזות של היעדים (SVG)
├── js/app.js           הלוגיקה: יומן, דירוג, מחשבונים, צ׳אט
└── vendor/leaflet/     ספריית המפות
```

## חשוב לדעת

- המחירים, הזמנים ודירוגי המישלן הם **הערכות**. המחיר האמיתי מופיע באתרי ההזמנה.
- סטטוס כשרות משתנה. תמיד בדקו תעודה בתוקף.
- לפני נסיעה לחו״ל בדקו את אזהרות המסע של המטה לביטחון לאומי.
- החופשות השמורות נשמרות בדפדפן במכשיר שלכם בלבד.
