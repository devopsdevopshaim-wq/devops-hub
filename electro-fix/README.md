# מעגל סגור — מרכז אבחון תקלות חשמל ואלקטרוניקה

באוויר: https://devopsdevopshaim-wq.github.io/devops-hub/electro-fix/

אתר בעברית לאבחון ותיקון תקלות בארונות חשמל תעשייתיים, בחשמל ביתי, בבתים חכמים ובאלקטרוניקה ברמת הכרטיס. מתארים את התקלה ומצרפים תמונות. Claude מאבחן אותה, נותן בדיקות מדידה מסודרות, בודק את הפתרון ומשרטט סכימת חיווט תקינה. האתר בודק את הסכימה אוטומטית.

## איך זה עובד

| שלב | מה קורה |
| --- | --- |
| 1. פתיחת תקלה | בוחרים תחום (תעשייתי, ביתי, בית חכם, אלקטרוניקה, אחר) וממלאים: ציוד, דגם, מתח הזנה, החלקים הבעייתיים, התסמינים, מה כבר נמדד, והחיווט הקיים. אפשר לצרף תמונות של הלוח או הכרטיס, שרטוטים, דפי נתונים ב-PDF ורשימות חיווט או קוד PLC. התמונות מוקטנות בדפדפן לפני השליחה. |
| 2. אבחנה | רמת סכנה ואזהרות בטיחות (LOTO, CAT, מתי לקרוא לחשמלאי). מה Claude זיהה בתמונות. סיבות אפשריות מדורגות באחוזים, עם דרך לאמת כל אחת. |
| 3. בדיקות מדידה | טבלה של בדיקות לפי הסדר: איפה למדוד, באיזה מכשיר, מה הערך התקין ומה המשמעות של ערך חריג. ליד כל בדיקה יש שדה שבו כותבים מה נמדד, וליד כל שאלת הבהרה יש שדה תשובה. |
| 4. המשך אבחון | הערכים והתשובות נשלחים אוטומטית בסבב הבא, יחד עם הערות ותמונות חדשות. Claude מעדכן את האבחנה בלי לחזור על בדיקות שכבר נעשו. |
| 5. פתרון ואימות | צעדי תיקון, רשימת חלקים ו״בדיקת הפתרון״: Claude עובר על הפתרון שלו מול כללים (קצרים, רציפות הארקה, ניתוק פאזה, התאמת הגנה לחתך, מתחי סליל, קוטביות, דיודת גלגול חופשי ועוד). |
| 6. סכימת חיווט | שרטוט של רכיבים עם סימוני ההדקים האמיתיים, וחוטים ממוספרים בצבעי IEC 60445, לצד טבלת חיווט מלאה (מ-, אל, צבע, חתך). אפשר להוריד את השרטוט כ-SVG או PNG, ולהדפיס את הדו״ח או לשמור אותו כ-PDF. |

### תכנון כרטיס (עורך מעגלים)

עמוד "תכנון כרטיס" הוא עורך לבניית מעגלים ובדיקתם, לפני שמזמינים כרטיס (PCB) או מחווטים.

- **תבניות מוכנות**: כרטיס ריק עם הזנת USB, נורית עם נגד טורי, ספק 3.3V מ-5V (AMS1117), דרייבר ממסר מיציאת בקר, כרטיס ESP32 בסיסי, מחלק מתח 12V לכניסת ADC, מהבהב עם טיימר 555, וכניסת 24V מבודדת לבקר (PC817). כל תבנית עוברת את הבודק בלי שגיאות והערות.
- **הוספת רכיבים**: נגדים, קבלים, סלילים, גבישים, נתיכים, נוריות, דיודות, טרנזיסטורים, MOSFET, רגולטורים, ESP32, Arduino Nano, 555, אופטוקפלר, חיישנים, מחברים, מקורות הזנה, לחצנים, ממסרים ומנועים.
- **עריכה**: לוחצים על פין ואז על פין אחר כדי לחבר חוט, וגוררים רכיב כדי להזיז אותו. בלוח העריכה משנים מזהה, ערך, סוג, פינים ו"מתח קבוע" לפיני הזנה. יש ביטול פעולה (Ctrl+Z), ו-Delete מוחק את מה שנבחר.
- **בדיקה חיה** בכל שינוי, ובנוסף לכללי החשמל: נורית בלי נגד טורי, דיודה או קבל אלקטרוליטי הפוכים, מתח עבודה של קבל נמוך מההזנה, סליל DC בלי דיודת גלגול חופשי (או עם דיודה הפוכה), טרנזיסטור בלי נגד בסיס, IC בלי קבל ניתוק או עם פין הזנה לא מחובר, רגולטור בלי קבלי כניסה ויציאה או שאמור להעלות מתח, ורכיב 3.3V שמחובר ל-5V.
- **Claude יתכנן לי**: מתארים מה הכרטיס צריך לעשות, ו-Claude בונה מעגל שלם עם ערכים מחושבים, בדיקה, רשימת חלקים והנחיות לעימוד ה-PCB.
- **בדיקה של Claude**: Claude עובר על המעגל שבעורך יחד עם ממצאי הבודק, ומציע תיקונים שאפשר להחיל או לבטל.
- **ייצוא וייבוא**: שרטוט SVG ו-PNG, רשימת חלקים CSV, וקובץ מעגל JSON לגיבוי ולשיתוף. העיצובים נשמרים בדפדפן.
- מכל סכימה בתיק אבחון אפשר ללחוץ "עריכה בעורך" ולהמשיך לעבוד עליה.

### ערכות מדידה לכרטיס המודפס

בעורך הכרטיסים, מתחת לשרטוט, יש חמש ערכות בדיקה. הן נבנות אוטומטית מהמעגל, עם ערך צפוי וטווח תקין לכל מדידה:

| ערכה | מה בודקים |
| --- | --- |
| בדיקה חזותית | כיוון קבלים אלקטרוליטיים, דיודות ונוריות, פין 1 של רכיבים משולבים, גשרי הלחמה |
| ללא מתח: קצרים ורציפות | התנגדות מכל קו הזנה ל-GND (שלילת קצר), רציפות GND והזנה לכל רכיב, נגדים במעגל, סלילי ממסרים, מפל קדמי של דיודות |
| הדלקה ראשונה | כיוון ספק מעבדה והגבלת זרם, זרם צריכה משוער, כל מתחי ההזנה, מתח על כל רכיב, זרם כל נורית, מתחים בצמתים, חום ברגולטור |
| בדיקה פונקציונלית | מצבי EN/BOOT, תדר ומחזור עבודה של 555, תנודת גביש, הפעלת ממסר (רוויה, מתח סליל, קוץ בניתוק), אופטוקפלר, לחצנים |
| בטיחות ובידוד | בדיקת מגר בין צדדים מבודדים, בידוד סליל-מגעים, מרווחים בכרטיס, רציפות הארקה |

הערכים הצפויים מחושבים בפותר DC קטן (`js/testkit.js`): נגדים, נוריות ודיודות (מפל קבוע), רגולטורים ומקורות הזנה. טרנזיסטורים ורכיבים משולבים נחשבים פתוחים (מצב מנוחה). רושמים ליד כל בדיקה מה נמדד (למשל `4.7k`, `3.29`, `12m`, `OL`), והאתר מסמן תקין או חריג. אפשר גם להדפיס דו״ח בדיקה עם השרטוט.

**מדידה וירטואלית**: כפתור בסרגל השרטוט. לוחצים על פין ורואים את המתח הצפוי שלו ביחס ל-GND, ואת הזרם וההספק ברכיב.

### תכנון חשמל לבית

עמוד "חשמל לבית" בונה תכנית חשמל ראשונית לדירה או לבית:

- **חדרים**: 15 סוגי חדרים עם ברירות מחדל (סלון, מטבח, חדרי שינה, ממ״ד, חדרי רחצה, כביסה, מרפסת, חצר, חניה ועוד), ותבניות מהירות לדירת 3, 4 ו-5 חדרים ולבית פרטי. לכל חדר קובעים שטח, שקעים, נקודות מאור, רשת וטלוויזיה, מזגן, ומכשירים במעגל ייעודי (תנור, כיריים אינדוקציה, מדיח, מקרר, כביסה, מייבש, דוד, עמדת טעינה, ארון תקשורת).
- **חלוקה למעגלים**: תאורה עד 10 נקודות למעגל (C10, ‏1.5 ממ״ר), שקעים עד 8 (C16, ‏2.5 ממ״ר), שקעי מטבח ואזורים רטובים בנפרד, מעגל ייעודי לכל מכשיר כבד. בחיבור תלת-פאזי: כיריים, מזגן מרכזי וטעינה תלת-פאזיים, ואיזון פאזות אוטומטי.
- **לוח החשמל הדירתי**: שרטוט חזיתי של הלוח. כולל מפסק ראשי, מגן ברק, נוריות סימון, ממסרי פחת 30mA מחולקים לקבוצות (סוג B לטעינת רכב), מאמתים ממוספרים עם צבע פאזה, קוצב זמן ומגען לדוד, ומקום שמור. גודל הלוח נבחר עם 25% רזרבה.
- **מרשם מעגלים**: טבלת כל המעגלים לפי הסדר בלוח (מאמת, כבל, פאזה, פחת, נקודות, הספק). אפשר להדפיס אותה בגופן גדול להדבקה על דלת הלוח.
- **עומס**: הערכת זרם לכל פאזה מול גודל החיבור, עם מקדמי ביקוש ובו-זמניות, ואזהרה כשהחיבור קטן מדי.
- **בית חכם**: בוחרים Wi-Fi ‏(Shelly), ‏Zigbee או KNX. מקבלים רשימת רכיבים לכל חדר (מודולי תאורה ותריסים, בקרי מזגן, חיישנים, גלאי עשן), דרישות חיווט (אפס בקופסאות, קופסאות עמוקות, כבל KNX, רשת), תוספות ללוח, ותרחישים כמו מצב שבת, יציאה מהבית ולילה טוב.
- **בדיקה של Claude**: שולחים את התכנית ומקבלים אזהרות, המלצות, טיפים לבית החכם ושאלות פתוחות.
- **הדפסה**: תכנית מלאה (נקודות, לוח, מרשם, המלצות ובית חכם) להדפסה או לשמירה כ-PDF.

התכנית היא הצעה ראשונית לפי נוהג מקובל. תכנון מחייב וביצוע — רק על ידי חשמלאי בעל רישיון מתאים.

### שרטוט אדריכלי → תכנון חשמל

עמוד "שרטוט אדריכלי" מקבל שרטוט קומה (תמונה או PDF; כל עמוד הוא קומה) ופורש עליו את כל החשמל:

- **ניתוח עם Claude**: Claude מזהה את סוג הנכס (דירה, בית, בניין), הקומות (כולל "קומה טיפוסית" שחוזרת כמה פעמים), הדירות והחדרים. לכל חדר הוא מחזיר מלבן על השרטוט, סוג, מידות מהשרטוט, דלתות וחלונות, וגם את דלת הכניסה ומיקום ללוח החשמל. האתר בודק חפיפות וחריגות, ואם יש — מבקש מ-Claude תיקון.
- **קנה מידה** מחושב מהמידות שכתובות בשרטוט, או בכיול ידני: לוחצים על שתי נקודות ומזינים את המרחק.
- **עריכה**: לוחצים על חדר כדי לשנות שם, סוג, דירה, מזגן, מספר שקעים, נקודות מאור, רשת ומעגלים ייעודיים. גוררים כדי להזיז, גוררים פינה כדי לשנות גודל, ובמצב "שרטוט חדר" מוסיפים חדר.
- **חשמל בכל חדר**: שקעים לאורך הקירות הרחק מדלתות (מעל המשטח במטבח, IP44 באזורים רטובים), מתג ליד הדלת (מחליף במסדרון), מאור ברשת על התקרה, מזגן על הקיר החיצוני, נקודות טלוויזיה ורשת, מעגלים ייעודיים, מאוורר, ולוח החשמל ליד הכניסה. לכל נקודה יש גובה, מעגל, מאמת, וגם הספק וזרם.
- **פירוט חדרים**: מידות, שטח, כמות נקודות, מעגלים בלוח, הספק מחובר וזרם לכל חדר.
- **לוח דירתי**: שרטוט הלוח, טבלת מעגלים עם זרם לכל מעגל, ובדיקות.
- **בניין**: עומס לכל דירה, מקדם בו-זמניות לפי מספר הדירות, שירותים משותפים (תאורה, מעלית, משאבות, חניון), חיבור מומלץ מחברת החשמל, חדר מונים, לוח ראשי, ושרטוט עמוד חשמל.
- **תלת-ממד**: הדירה בתלת-ממד (three.js), עם קירות ופתחי דלתות וחלונות, הרצפה עם השרטוט עצמו, וכל נקודות החשמל בגובה שלהן. במעבר עכבר על נקודה מוצגים המעגל והזרם. יש גם מצב "קירות חתוכים" ומבט מלמעלה.
- **שרטוט לדוגמה**: כפתור שפותח דירת 4.5 חדרים כדי לנסות בלי קובץ.
- אפשר להעביר דירה ל"חשמל לבית", ולהדפיס את כל הפרויקט.

בלי מפתח API (למשל ב-GitHub Pages) עובדים בהעתק-הדבק מול claude.ai, ויש כפתור להורדת השרטוטים המוכנים לצירוף. three.js ו-pdf.js נמצאים בתיקייה `vendor/` (רישיונות MIT ו-Apache 2.0 מצורפים).

### הבודק האוטומטי

כל סכימה עוברת בדיקה בקוד (`js/netlist.js`). הבודק מאחד את ההדקים לצמתים חשמליים ומחפש:

- קצר: פאזה, אפס, הארקה או פסי DC שונים על אותו צומת
- אפס והארקה מחוברים יחד (עם הבחנה בנקודת פיצול PEN ובהארקת 0V של PELV)
- מוליך ירוק-צהוב שאינו הארקה, הארקה בצבע אחר, אפס שאינו כחול, ופאזה בכחול
- חוטים שמפנים להדק או לרכיב שלא קיימים, וחוטים כפולים
- הדקי הזנה לא מחוברים ורכיבים מנותקים
- מנוע, ממיר תדר, ספק או שקע של מתח רשת בלי הדק הארקה

אם נמצאו שגיאות, השרת מחזיר אותן ל-Claude לתיקון (סבב אחד), ורק אז מציג את התוצאה. גם במצב העתק-הדבק הבדיקה רצה בדפדפן.

### עוד באתר

- **התיקים שלי**: כל תיק נשמר בדפדפן (IndexedDB) עם התמונות וכל הסבבים. אפשר לחפש ולסנן לפי תחום.
- **מחשבונים**: חוק אוהם והספק, מפל מתח וחתך כבל (כולל כושר הולכה משוער ומפסק מתאים), זרם מנוע וכיול תרמי, קוד צבעים לנגד, ונגד טורי ל-LED.
- **מקרא ובטיחות**: צבעי מוליכים, סימוני הדקים נפוצים וסדר בדיקה בטוח.

## הפעלה

צריך Node.js 18 ומעלה ומפתח API של Anthropic.

```bash
cd electro-fix
npm install
ANTHROPIC_API_KEY=sk-ant-... npm start
```

ואז פותחים את `http://localhost:8790`.

המפתח נשמר רק בשרת ולא נשלח לדפדפן.

| משתנה | מה הוא עושה |
| --- | --- |
| `PORT` | פורט השרת (ברירת מחדל 8790) |
| `FIX_MODEL` | המודל (ברירת מחדל `claude-opus-5-5`) |
| `FIX_EFFORT` | עומק החשיבה: `low` / `medium` / `high` / `xhigh` / `max` (ברירת מחדל `high`) |
| `ACCESS_CODE` | קוד גישה שהאתר מבקש לפני שימוש ב-AI. חובה אם השרת פתוח לאינטרנט, אחרת כל אחד יכול להשתמש במפתח שלכם. |

אפשר להעלות את התיקייה כמו שהיא לכל שירות שמריץ Node (Render, Railway, Fly.io וכו׳) עם `npm start`.

### בלי מפתח API

אם השרת רץ בלי מפתח, או כשפותחים את `index.html` ישירות, האתר עובר למצב העתק-הדבק. מעתיקים הנחיה מוכנה ל-claude.ai, מצרפים שם את התמונות, ומדביקים את התשובה בחזרה. התצוגה, הסכימה והבדיקה האוטומטית עובדות גם במצב הזה.

הבדיקות מריצות את הבודק האוטומטי על סכימת מתנע ישיר (DOL) תקינה ועל גרסאות שבורות שלה (קצר, N-PE, צבעים, הדקים חסרים), על כל התבניות, ועל שגיאות אלקטרוניקה נפוצות (נורית בלי נגד, קבל הפוך, ממסר בלי דיודה, טרנזיסטור בלי נגד בסיס, 3.3V על 5V ועוד). הן בודקות גם את השרטוט, את בניית ההודעות ל-Claude ואת תקינות הסכמה ל-structured outputs.

## פרטים טכניים

- התשובה מגיעה כ-JSON לפי סכמה קבועה (structured outputs). כך אפשר להציג כל חלק בנפרד ולבדוק את הסכימה בקוד.
- חשיבה אדפטיבית עם תקציר חשיבה שמוצג בזמן ההמתנה. ההנחיות וההיסטוריה של התיק נשמרות במטמון (prompt caching) כדי לחסוך בעלות בסבבי המשך.
- מופעל גיבוי אוטומטי בצד השרת (`fallbacks: "default"`): אם המודל מסרב לבקשה, היא עוברת למודל חלופי.

> עבודה במתח רשת מסוכנת, ובישראל מותרת רק לחשמלאי בעל רישיון מתאים. האבחון הוא כלי עזר מקצועי ואינו מחליף בדיקה של חשמלאי מוסמך.
