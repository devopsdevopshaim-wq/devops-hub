# ספר — סטודיו לכתיבת ספרים

אתר בעברית שהופך את הסיפור שלכם לספר קריאה מקצועי. מספרים במילים פשוטות, בלי הגבלת אורך, ו-Claude מנסח את הטקסט בשפה ספרותית גבוהה. האתר מעמד את הספר לעמודים אמיתיים בגודל דפוס, עם תמונות ואיורים, ומוציא קובץ PDF מוכן להדפסה.

## איך זה עובד

| שלב | מה עושים |
| --- | --- |
| 1. פרטי הספר | שם, מחבר, סוגה (ממואר/דוקו, ביוגרפיה, דרמה, רומנטי, מתח, היסטורי, פנטזיה, השראה, ספר ילדים), קול מספר, משלב לשוני, אורך (24 עד 450 עמודים או כל מספר אחר) וגודל הספר המודפס. |
| 2. הסיפור שלך | כותבים חופשי בקטעים, בלי הגבלת מילים. אפשר גם לייבא קבצי טקסט או להקליט בקול (הקלדה קולית בעברית). |
| 3. תמונות וציורים | מעלים צילומים ובוחרים איפה כל אחד יופיע: בפתיחת פרק, בסופו, בעמוד מלא או על הכריכה. כל צילום אפשר להפוך לציור בעבודת יד (רישום עיפרון, פחם בספיה, צבעי מים, ציור שמן). ההמרה נעשית כולה בדפדפן, והצילום לא נשלח לשום מקום. אפשר גם להזמין ציור חדש מתיאור במילים (צבעי מים, שמן, עיפרון, פחם, דיו, גואש לילדים), או ציור לכל הפרקים בלחיצה אחת בשלב 4. |
| 4. כתיבת הספר | Claude בונה מבנה פרקים שמתאים לאורך שבחרתם, ואז כותב פרק אחרי פרק. כל פרק אפשר לערוך ביד, להמשיך או לשכתב לפי הערה. |
| 5. הספר המוכן | ארבעה סגנונות עיצוב יוקרתיים לבחירה: **מלכותי** (זהב על כחול לילה), **קלאסי** (בורדו וזהב), **מודרני** (שחור וזהב דק), **וינטג׳** (עור חום ונייר עתיק). בכל סגנון: כריכה עם אותיות בהטבעת זהב, מסגרות עם פינות מעוטרות, פתיחת פרק עם אות עברית גדולה (א, ב, ג…), אות פתיחה מוגדלת ומילים ראשונות מודגשות, עיטורים בין סצנות, ותמונות במסגרת. תצוגת כפולות או עמוד בודד, כריכה קדמית ואחורית, עמוד שער, הקדשה, תוכן עניינים עם מספרי עמודים, כותרות רצות ומספור. כפתור ״התאמה ליעד העמודים״ מכוון את גודל האות. ייצוא ל-PDF (דרך חלון ההדפסה), ל-Word ולטקסט. |

בספר על חיים אמיתיים (ממואר, ביוגרפיה) Claude מקבל הוראה לא להמציא עובדות, אנשים או אירועים. כשחסר חומר, הוא מעמיק ברגש, בהקשר ובהרהור. לכן, כדי לקבל ספר עבה ועשיר, צריך לכתוב מספיק זיכרונות. האתר מראה כמה מילים יש וכמה צריך.

## הפעלה

### עם כתיבה אוטומטית (מומלץ)

צריך Node.js 18 ומעלה ומפתח API של Anthropic.

```bash
cd book-studio
npm install
ANTHROPIC_API_KEY=sk-ant-... npm start
```

ואז פותחים את `http://localhost:8787`.

המפתח נשמר רק בשרת ולא נשלח לדפדפן. משתנים נוספים:

| משתנה | מה הוא עושה |
| --- | --- |
| `PORT` | פורט השרת (ברירת מחדל 8787) |
| `BOOK_MODEL` | המודל (ברירת מחדל `claude-opus-5-5`) |
| `ACCESS_CODE` | קוד גישה שהאתר יבקש לפני כל שימוש ב-AI. חובה אם השרת פתוח לאינטרנט, אחרת כל אחד יכול להשתמש במפתח שלכם. |
| `OPENAI_API_KEY` | אופציונלי: ציורים באיכות הגבוהה ביותר דרך שירות התמונות של OpenAI (המודל נקבע ב-`IMAGE_MODEL`, ברירת מחדל `gpt-image-1`). |

אפשר להעלות את התיקייה כמו שהיא לכל שירות שמריץ Node (Render, Railway, Fly.io וכו׳) עם `npm start`.

### בלי שרת (מצב העתק-הדבק)

פותחים את `index.html` בלחיצה כפולה, או את הכתובת ב-GitHub Pages: https://devopsdevopshaim-wq.github.io/devops-hub/book-studio/

כל פעולת כתיבה פותחת חלון עם הנחיה מוכנה. מעתיקים אותה ל-[Claude.ai](https://claude.ai), ומדביקים את התשובה בחזרה. כל שאר האתר (עימוד, תמונות, PDF) עובד בדיוק אותו דבר.

## עלות וזמן

כל פרק הוא בקשה נפרדת ל-Claude. חומר הגלם נשמר במטמון בין הפרקים כדי לחסוך. ספר של 350 עמודים הוא כ-20 פרקים, ולכן לוקח זמן. אפשר לעצור בכל רגע ולהמשיך אחר כך.

## שמירה ופרטיות

כל הטקסטים והתמונות נשמרים רק בדפדפן (IndexedDB), בלי חשבון ובלי שרת מסד נתונים. אפשר לנהל כמה ספרים (״הספרים שלי״). כדאי ללחוץ מדי פעם על ״גיבוי הספר לקובץ״ בתחתית העמוד, כי ניקוי נתוני הדפדפן מוחק את הספרים.

## נגישות

ניווט מלא במקלדת, תוויות לקוראי מסך, והודעות סטטוס שמוקראות. תפריט נגישות עם הגדלת טקסט, ניגודיות גבוהה, רקע בהיר, גופן קריא, הדגשת קישורים, ריווח שורות ועצירת אנימציות. יש גם הצהרת נגישות. האתר מותאם לטלפון.

## ציורים חדשים מתיאור

- **עם השרת:** Claude כותב לכל ציור הנחיה מקצועית באנגלית (סגנון, תקופה, קומפוזיציה, תאורה).
- **מי מצייר:** אם הוגדר `OPENAI_API_KEY`, הציור נוצר אצל OpenAI. אחרת, ובאתר ב-GitHub Pages, הציור נוצר בשירות הציור החינמי Pollinations.
- **פרטיות:** לשירות הציור נשלח רק התיאור במילים, לא הצילומים שלכם.
