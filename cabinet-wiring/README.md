# ארון־פלאן — חיווט והרכבת ארון פיקוד

אחרי מיזוג ל-main האתר זמין כאן: https://devopsdevopshaim-wq.github.io/devops-hub/cabinet-wiring/

מעלים PDF של תכנית החיווט של ארון הפיקוד, והמערכת בונה ממנו את כל החיווט:

- **רשימת חוטים נקודה לנקודה.** לכל חוט: מספר, מאיפה (תג והדק), לאן, תפקיד במעגל (כוח, N, פיקוד AC/DC, ‏0V, ‏PE, אותות), צבע, חתך, סוג חוט (H05V-K / H07V-K / כבל), אורך משוער, שרוול קצה (צבע DIN 46228-4, TWIN כשיש שני חוטים בהדק), אורך קילוף ומומנט הידוק.
- **הסבר לכל חוט.** מה החוט עושה במעגל, מה קורה כשיש בו מתח, איך מחווטים אותו ואיך בודקים אותו. ההסבר מופיע כשעומדים על החוט בציור הארון, ובחלון הפרטים כשלוחצים עליו.
- **ציור הארון.** פלטת הרכבה, תעלות, מסילות DIN, רכיבים, דלת ומכשירים בשטח. כל חוט מצויר במסלול שלו בתעלות ובצבע שלו. אפשר להגדיל ולהזיז, לסנן לפי תפקיד, וללחוץ על רכיב כדי להדגיש את כל החוטים שלו.
- **עמדת חיווט.** חוט אחד בכל פעם, בסדר עבודה נכון (כוח, אפס, פיקוד, אותות, הארקה): ציור מדויק של החוט (צבע, קילוף, שרוול DIN 46228, שרוולי סימון, אורך), מסלול בתעלות, שישה שלבים לסימון (מקשים 1–6), טבעת התקדמות, רצף וזמן משוער לסיום, צליל "קליק" וחגיגה קטנה בכל חיבור, ומקשי קיצור (Enter, חצים, R).
- **הדרכה קולית באנגלית מקצועית.** קול נשי מהדפדפן מקריא לכל חוט: סוג, חתך, צבע, אורך, קילוף ושרוול, מאיפה, מסלול, לאן, מה החוט עושה והידוק. כתוביות עם המשפט הנוכחי, הקראה אוטומטית, מהירות ובחירת קול (`js/voice.js`).
- **הרכבה ובדיקות.** סימון הפלטה, תעלות ומסילות באורכים, סדר הרכיבים בכל מסילה, רכיבי הדלת, רשימת חיתוך וקנייה לפי צבע וחתך, ספירת שרוולים, ובדיקות לפני הפעלה (רציפות הארקה, בידוד 500V, הפעלה בלי עומס).
- **הדפסה.** תיק חיווט מלא (שער, ציור, רכיבים, תכנית הרכבה, חוטים לפי סדר החיווט עם תיבות סימון, רשימת חיתוך, טופס בדיקות וחתימות), שרוולי סימון לכל חוט (מקור / יעד), CSV ל-Excel, ‏SVG של הציור ו-JSON לגיבוי.
- **ארון בתלת־ממד.** מעטפת במידות סטנדרטיות (RAL 7035) עם דלת שנפתחת ונסגרת, לחצנים, נוריות ולחצן חירום על הדלת, לוחית זיהוי ומדבקת אזהרה. בפנים: פלטה, מסילות, תעלות (עם או בלי מכסים), הרכיבים עם התג והשם, וכל חוט כמוליך בצבע ובעובי שלו. עומדים על חוט כדי לראות את ההסבר; לחיצה על רכיב מציגה את פרטיו. כרטיס הארון מפרט מידות, הגנה, מסילות, תעלות ומטרים של חוט. אפשר להוריד תמונה.
- **סימון על ה-PDF.** כשבוחרים חוט, המקומות של התגים ושל מספר החוט מסומנים על עמוד התכנית.

## תכניות שכבר נקראו במלואן

`js/library/` מכיל קריאה מלאה של תכניות מסוימות. כשמעלים PDF שהטקסט שלו מתאים (למשל 208-B, ‏B CABINET, הגדוד העברי 53), הפרויקט נטען מיד עם כל החוטים, החתכים, הצבעים והערות התקנות, בלי לחכות לבינה מלאכותית.

## איך התכנית נקראת

| מצב | מתי | איך |
| --- | --- | --- |
| שליפה מהטקסט | רשימת חוטים או תכנית מהדקים שיוצאו מ-EPLAN, ‏SEE ודומיהם | רץ מיד בדפדפן, בלי AI. מזהה שורות כמו `101  -X1:1  -Q1:1  BK  2.5 mm²  H07V-K`, וגם רשימת חלקים (`-K1  Contactor 3RT2016`). |
| קריאה אוטומטית (באתר החי) | שרטוט סכמטי גרפי או סריקה | מיד אחרי ההעלאה, אם אין בטקסט רשימת חוטים: העמודים נשלחים כתמונות לשרת n8n של האתרים (`hasadna-hubs`, ‏Gemini), שלושה עמודים בכל בקשה, והתשובות מתאחדות לרשימה אחת. אין צורך במפתח. |
| קריאה עם Claude | שרטוט סכמטי גרפי (רוב התכניות) | השרת שולח את ה-PDF עצמו ל-Claude, שמחזיר JSON לפי מבנה קבוע (`js/prompts.js`). צריך את השרת עם מפתח API. |
| Claude.ai בהעתק-הדבק | בלי שרת (למשל ב-GitHub Pages) | מעתיקים את הבקשה, מצרפים את ה-PDF בצ'אט ב-Claude.ai, ומדביקים את התשובה. |
| ייבוא JSON / הזנה ידנית | גיבוי, העברה, או תכנית קטנה | עריכת כל חוט ורכיב בטבלאות. |

כל מה שלא כתוב בתכנית מושלם לפי כללים ומסומן בכוכבית:

- **צבע** לפי IEC 60204-1: כוח שחור (או L1 חום / L2 שחור / L3 אפור לפי IEC 60445, בהגדרות), אפס תכלת, PE ירוק-צהוב, פיקוד AC אדום, ‎+24V כחול כהה, ‎0V לבן-כחול, מתח זר כתום.
- **תפקיד** לפי הדקי הרכיבים (L1–L3, ‏T1–T3, ‏A1/A2, ‏13-14, ‏95-96, ‏I0.0, ‏Q0.0, ‏+/0V, ‏PE) ולפי הצומת: חוטים שמחוברים דרך מהדק או דרך הגנה סגורה מקבלים אותו פוטנציאל.
- **סוג רכיב** לפי השם (מגען, ממסר, ספק, בקר…) ולפי קידומת התג (IEC 81346-2 ו-IEC 60617: ‏X, ‏K, ‏KM, ‏Q, ‏F, ‏A, ‏M, ‏S, ‏H, ‏B…).
- **חתך** לפי ההגדרות (ברירת מחדל: כוח 2.5, פיקוד 0.75, PE כמו הכוח עד 16 ממ"ר).

## הפעלה

### בלי שרת

פותחים את האתר. הכל עובד בדפדפן: קריאת PDF, שליפה מהטקסט, ציור, חיווט, הדפסה. הקריאה עם Claude עובדת בהעתק-הדבק.

### עם Claude דרך השרת

צריך Node.js 18 ומעלה ומפתח API של Anthropic.

```bash
cd cabinet-wiring
npm install
ANTHROPIC_API_KEY=sk-ant-... npm start
```

ואז פותחים את `http://localhost:8790`.

| משתנה | מה הוא עושה |
| --- | --- |
| `PORT` | פורט השרת (ברירת מחדל 8790) |
| `WIRING_MODEL` | המודל (ברירת מחדל `claude-opus-5-5`) |
| `ACCESS_CODE` | קוד גישה שהאתר מבקש לפני שימוש ב-AI. חובה אם השרת פתוח לאינטרנט. |

ה-PDF נשלח כמסמך (עד 30MB), יחד עם הטקסט שנשלף ממנו כעזרה לקריאת מספרים קטנים. התשובה חוזרת בזרימה, והאתר מראה כמה חוטים כבר נקראו. אם המודל מסרב לבקשה, השרת של Anthropic מעביר אותה למודל חלופי (`fallbacks: "default"`).

## חיבורים ומהדקים, ושרטוט הרכבה

- **שרטוט הרכבה** (לשונית "פריסת ארון"): פלטה, תעלות, מסילות ורכיבים עם תגים ומידות, במסגרת עם רשת אזורים (A1, B3…) וטבלת כותרת. החוטים מוסתרים ומופיעים רק לרכיב, חוט או תפקיד שנבחרו; "כל החוטים" מציג את כולם. בכרטיס הרכיב מופיע האזור שלו בשרטוט.
- **חיבורים ומהדקים** (לשונית 5): לכל פס מהדקים, לכל הדק — מה מחובר אליו בתוך הארון, ומה יוצא ממנו לשטח או לארון אחר באתר (כבל וגיד). לחיצה על ארון אחר פותחת אותו בדיוק בהדק התואם.
- **מעבר בין ארונות** של אותו אתר מכל לשונית, ובמסך האתר — תכנית חיבורים בין הארונות (כל כבל עם מספר, סוג, אורך וגידים).

## כרטיס רכיב

לוחצים על כל רכיב — בציור הארון, בתלת־ממד (כולל ציוד השטח שליד הארון: רמזור, לחצני חירום, סורקים, מנועים), ברשימת הרכיבים, בקצה של חוט או במסך האתר — ונפתח כרטיס: מה הרכיב עושה, איפה הוא, וטבלה של כל ההדקים שלו עם מספר החוט, הצבע, החתך ולאן הוא מגיע. במכשיר בשטח רואים את המסלול המלא דרך פס המהדקים עד הבקר או הממסר בארון, ואת הכבל המומלץ לשטח. מהכרטיס עוברים לחוט או לרכיב שבצד השני (עם "חזרה"), ואפשר לחווט רק את הרכיב הזה, שלב אחר שלב.

## גרסת Claude — קריאה אוטומטית של כל תכנית

התכנית 208-B נקראת מיד כי הקריאה שלה שמורה באתר. כל תכנית אחרת היא שרטוט שצריך לקרוא. בגרסת Claude של האתר (claude.ai, הקישור מופיע במסך "תכנית") Claude קורא את השרטוטים בעצמו, עמוד אחרי עמוד, על החשבון של המשתמש, בלי מפתחות ובלי שרת: כל עמוד נשלח כתמונה מלאה ועוד 4 הגדלות, התוצאות מתאחדות, ועמודים שנקראו נשמרים כדי שאפשר לעצור ולהמשיך.

הגרסה נבנית מאותם קבצים: `python3 tools/build-claude-app.py OUT_DIR` ואז פרסום של `OUT_DIR/index.html` עם קבצי `js/` כ-Artifact עם היכולות `sample` (עם תמונות) ו-`downloads`.

## אתרי התקנה

אתר = כמה ארונות במקום אחד. בדף הבית: "אתר חדש", ואז גוררים אליו את כל הקבצים של הפרויקט בבת אחת:

- כל PDF של תכנית חיווט הופך לארון באתר (עם קריאת השרטוטים, כמו בהעלאה רגילה).
- כל קובץ אחר (תמונות, DWG, Excel, מסמכים) נשמר בקבצי האתר, בנפרד לכל אתר, ואפשר להוריד אותו בחזרה.

במסך האתר: כרטיס לכל ארון, תכנית התקנה במבט על (גוררים ארונות, מסובבים, מגדירים מידות חדר וגובה מגש), האתר בתלת־ממד עם המגש והכבלים, וטבלת כבלים בין ארונות. כבלים מוצעים אוטומטית כשאותם שמות אותות מופיעים במהדקים החיצוניים של שני ארונות, או כשבתכנית כתוב "מלוח X"; אפשר גם להוסיף כבל ידנית. לכל כבל: סוג (NYY-J לכוח, LiYY/LiYCY לפיקוד עם 20% רזרבה, Cat6 לתקשורת), אורך לחיתוך וטבלת גידים. מערך ההתקנה מסביר שלב אחר שלב מההכנה ועד המסירה, ומודפס כתיק אתר עם טבלאות בדיקה.

## שמירה ופרטיות

הפרויקטים והאתרים נשמרים ב-IndexedDB של הדפדפן (ועותק ב-`localStorage` כשיש מקום), וכך גם ה-PDF, תמונות העמודים וקבצי האתרים. שום דבר לא נשלח לשרת, חוץ מה-PDF כשלוחצים "קריאה עם Claude".

## מגבלות

- הפריסה אוטומטית ומשמשת לחיווט ולהערכת אורכים. היא לא מחליפה את שרטוט הפריסה המאושר של הלוח.
- צבעים, חתכים ומומנטים שהושלמו הם ערכים מקובלים. צריך לאמת אותם מול התכנית, דפי היצרן ומהנדס החשמל.
- Claude קורא שרטוטים היטב, אבל בתכנית ארוכה או מטושטשת כדאי לעבור על רשימת החוטים ועל ההערות שהוא מחזיר. כל חוט אפשר לבדוק מול ה-PDF בכפתור "בתכנית".
- עד 40 עמודים נשמרים בדפדפן לתצוגה.
